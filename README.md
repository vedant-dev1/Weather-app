# Weather Forecast Web App

A modern and responsive Weather Forecast Web Application built using HTML, CSS, and JavaScript.

## Features

* Search weather by city name
* Real-time weather information
* Current temperature display
* Weather condition and icons
* Humidity and wind details
* 4-Day weather forecast
* Responsive and user-friendly interface
* Error handling for invalid city names

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API

## How It Works

The application uses the OpenWeather API to fetch live weather data based on the city entered by the user. The fetched data is processed using JavaScript and dynamically displayed on the webpage.

## Setup

1. Generate your own API key from OpenWeather.
2. Replace the API key in the JavaScript file.
3. Open `index.html` in your browser.

## Project Purpose

This project was created to practice API integration, asynchronous JavaScript, DOM manipulation, and responsive web design while building a real-world application.
